# Security policy

Registry validation is static: it parses submitted YAML and checks evidence fields. It does not install, import, execute, or sandbox third-party plugins.

Do not put API keys, access tokens, cookies, private repository URLs, personal data, or real credentials in Issues, Pull Requests, examples, or registry records.

For a sensitive vulnerability in this registry's own scripts or workflow, use GitHub's private vulnerability reporting. For a vulnerability in a listed plugin, contact that plugin's maintainer first and avoid publishing exploit details in this repository.
