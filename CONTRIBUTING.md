# Contributing

Thank you for improving the DeepSeek Harness / DSH plugin ecosystem.

1. Do not submit Skills, MCP servers, generic Agent projects, or unrelated libraries as DSH plugins.
2. Pin the exact Git commit used as evidence. Moving branches such as `main` are not accepted as review evidence.
3. Provide an SPDX license identifier and evidence from the pinned source.
4. Describe requested permissions and data flow without claiming that a manifest or source review proves runtime safety.
5. Keep the Chinese summary factual and short. Installation tutorials live on 52dsh.com and are linked from the record.
6. Run `npm install` and `npm run check` before opening a Pull Request.

The maintainers may keep a submission in `candidates/` until its identity, license, compatibility, and evidence level are clear. See [moderation policy](docs/moderation-policy.md).
